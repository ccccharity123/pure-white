# 纯白

独立布局与主题编辑器。已在 SillyTavern 1.19.1 验证，适配 TauriTavern 2.4.0 的 SillyTavern 1.19.0 兼容前端。使用酒馆的扩展设置保存模板，通过原生主题快照生成可分享的 UI 主题。

## 安装

1. 将 ZIP 解压到 SillyTavern 数据目录中当前用户的 `extensions/`。默认单用户路径是 `SillyTavern/data/default-user/extensions/`。
2. 确认文件位于 `extensions/tavern-layout-editor/manifest.json`，然后刷新酒馆。Docker 安装请解压到宿主机映射的数据目录。管理员也可以把扩展目录放进 `SillyTavern/public/scripts/extensions/third-party/` 供所有用户使用。
3. 打开输入栏旁的魔杖菜单，点击「纯白」。已有旧版时可覆盖同名扩展目录，原模板继续可用。
4. TauriTavern 可解压到实际数据目录的 `default-user/extensions/`。全局安装路径是该数据目录的 `extensions/third-party/`。解压后重启 TauriTavern。

## 编辑与保存

- 顶栏、聊天区、输入栏和页面支持实时预览。宽度百分比以页面可用宽度为基准，极窄时会保留操作区所需空间。最大宽度和间距使用 px。顶栏的上下间距也会调整聊天面板起点。
- 移动端覆盖在页面宽度 ≤ 1000 px 时生效。留空或点击「继承」可沿用桌面值。「清空图片」可在移动端显式清掉继承来的图片。
- 「应用」保存当前布局和本轮模板操作。「取消」撤销本轮修改并恢复打开时的布局。「恢复默认」先预览酒馆原生布局，再用「应用」保存。
- 背景接受可直接加载的 HTTPS 图片链接。设置「底色不透明度」只影响底色。「图片不透明度」与「黑色遮罩不透明度」只影响图片。
- 在「模板」中可导入、导出可编辑模板 JSON。导入后可随即编辑，点「应用」保存。

## 点选元素与场景

- 点击「点选界面元素」，再点击原生发送按钮、顶栏图标、聊天气泡、头像或面板。编辑区会跳到该对象，并按当前视口选择桌面或移动端。可按 Esc 退出点选。
- 「按钮与图标」包含全局、顶栏组和单按钮三层。单按钮的填写值覆盖组设置。可选内置图标或 HTTPS 图片。
- 「消息与头像」分别设置用户和角色气泡与头像。对白对应引号内容，旁白对应斜体内容，引用和时间戳分别设置。
- 「面板与菜单」覆盖角色列表、世界书、用户设置、扩展面板、原生弹窗和两个输入栏菜单。四个顶部原生抽屉支持移动端底部停靠。TauriTavern 自己的专属面板沿用宿主布局。
- 「入口与彩蛋」可配置输入栏的「换主题」「返回底部」及其名称。移动端可收进「更多」。彩蛋支持单击、双击、长按、文字、图片、动效和可选提示音。提示音受系统 WebView 的音频权限影响。
- 在「场景匹配」填入当前聊天 ID、角色名称或本地时段，再在「模板」开启自动切换。匹配优先级为聊天、角色、时段。手动选择模板后会固定当前选择，可在同处恢复自动切换。

## 分享原生主题

在「模板」输入一个新主题名称，点击「导出酒馆原生主题」。导出会读取当前酒馆的主题设置，并在其 Custom CSS 中更新扩展的标记区块。主题使用酒馆原生界面节点，可在同版本酒馆中独立使用。

接收方打开顶部「用户设置 → UI 主题」，使用主题导入按钮选取 JSON，再在主题下拉框中选中导入的名称。同名主题需要先换名或处理旧主题。主题保留导出方的 Custom CSS，分享前可在酒馆中查看这段样式。图片会从各自的 URL 加载。

应用布局的酒馆也可以使用原生主题。预览与已应用的扩展布局会叠加在当前原生主题上。想单独查看原生主题时，可以切换到默认布局或禁用扩展。

原生主题适用静态样式。输入栏新增入口、界面彩蛋和场景匹配需在接收方安装纯白并导入可编辑模板。两种宿主可使用同一份可编辑模板。

## 纯白 1.2 的三个入口

- 「消息与头像 → 消息信息显隐」可分别设置时间戳、消息编号、模型信息、Token 数和推理过程。选「点开看」后，可在消息里的「消息信息」按钮展开或收起。模型名和 Token 数取自酒馆已有记录。推理过程可设置初始展开或折叠，之后可用消息自带的按钮切换。
- 「按钮与图标 → 手机按钮重排」可为发送、停止、继续、魔杖和聊天菜单选择输入框左侧、右侧或原位，并设置同侧顺序。可选的「消息更多」提供编辑末条、复制末条和重抽。
- 「模板 → 局部套用模板」支持选择已保存模板或读取一份可编辑模板 JSON。勾选区域后点击「套用所选区域」，来源已填写的字段覆盖当前模板对应值。其余设置会保留。可继续编辑、应用或取消。
- 原生主题 JSON 支持静态显隐。「点开看」、模型名称文字、推理初始展开状态和手机按钮重排由扩展运行，可随可编辑模板分享。

## 原生菜单编辑

打开「纯白」，点击「点选界面元素」，再点魔杖或聊天操作按钮打开菜单。点项目即可编辑，点面板留白可编辑面板。菜单打开时再次点入口可编辑入口本身。「原生菜单」也提供列表选择。

- 入口与项目可调整图标和外观。单个项目还可改名、移到第一位、置顶、上移、下移、移入分组或「更多」。分组在「展开面板」中新建，项目在各自的「移入分组」中指派。
- 面板支持宽度、最大高度、列数、间距、背景图片和打开位置。「全局菜单风格」是默认层，菜单和项目可分别覆盖。手机覆盖留空时沿用已有设定。
- 动态项目通过稳定的扩展标识、DOM ID 或翻译键识别。缺少稳定标识的项目保留原功能。扩展停用或缺失时，模板中的对应配置会保留，可在列表看到「暂不可用」。
- 分享完整菜单请在「模板」导出可编辑 JSON。原生主题保留已有 Custom CSS，并携带可独立生效的面板与项目外观。导出界面会列出需要纯白还原的改名、排序、分组及其他菜单效果。

### iOS TT 安装

适用 TauriTavern 2.4.0 中允许执行第三方前端扩展的配置。安装包是酒馆扩展，解压后的目录与网页版共用。将 `tavern-layout-editor/` 放到宿主实际数据根目录的 `default-user/extensions/`，随后重启。若 iPhone 无法直接访问数据目录，可先在桌面 TauriTavern 安装，再用宿主的 TT Sync 同步「Local extensions」，重启 iPhone 上的 TT 后在魔杖菜单打开纯白。

官方公开 TestFlight 的默认外测配置关闭第三方扩展管理及执行。请用允许第三方扩展的 TT 配置安装。需要静态外观时，可在宿主允许导入 UI 主题的情况下选择原生主题 JSON。[TT iOS 策略](https://github.com/Darkatse/TauriTavern/blob/v2.4.0/docs/CurrentState/iOSPolicy.md) · [扩展目录](https://github.com/Darkatse/TauriTavern/blob/v2.4.0/docs/CurrentState/ThirdPartyExtensions.md) · [TT Sync](https://github.com/Darkatse/TauriTavern/blob/v2.4.0/docs/CurrentState/Sync.md)
